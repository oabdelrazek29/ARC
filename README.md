# ARC

AI-powered adaptive learning — turn any goal into an RPG-style skill tree with XP, boss battles, and an AI coach.

## Local development

```bash
npm install
cp .env.example .env.local   # add your API keys (see docs/ARC_KEYS.md)
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
